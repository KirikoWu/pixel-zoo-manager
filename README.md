# 🦁 像素动物园 · PIXEL ZOO MANAGER

一款**浏览器直接可玩**的像素风动物园经营模拟游戏。以「天」为单位经营你的小小动物园：照顾动物、建造设施、观察游客、应对随机事件，看着动物园一天一天变热闹。

> 单文件 HTML5 游戏（`index.html`），双击即可游玩，无需安装、无需联网。

---

## 🎮 怎么玩

**核心循环**：规划 → 照顾动物 → 建造设施 → 开园前检查 → 开门营业 → 游客入园游玩 → 日终结算 → 进入下一天。

- **🦁 动物系统**：狮子、水豚（小熊猫森林后续解锁）。每只动物都有健康 / 饱食 / 状态（散步、进食、睡觉、生病），需要喂食与治疗。
- **🏗️ 建造系统**：道路、食品摊、厕所、长椅、垃圾桶、路灯、拆除。所有设施都有真实的像素地图实体，放置有红绿预览与弹跳动画。
- **🚶 游客系统**：家庭、摄影师、动物专家三类游客，真实地在园区道路行走、排队、购买、参观。需求气泡直接显示在头顶（🍔🚻📷💤😡）。
- **😊 满意度系统**：顶部常驻满意度仪表，营业期间实时变化，日终正式结算并给出正负因素解释。
- **🎲 随机事件**：动物生病、人流高峰、热浪、食品延迟、摄影团涌入，事件先在地图上可见，再给一句短提示。
- **🏅 成长目标**：开业周里程碑（服务 60 名游客 / 满意度 70 / 升级栖息地），完成后解锁小熊猫森林。
- **📖 新手教程**：5 步交互式引导，一次只教一个动作。
- **🎵 音频**：三套循环 BGM（标题 / 规划 / 营业）+ 全套交互音效与提示音，Web Audio 合成，无需外部资源。

## 🖥️ 运行方式

直接双击打开 `index.html`，或在项目目录启动本地服务器：

```bash
# 任意一种即可
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 首次进入后点击一次页面（浏览器自动播放策略），音乐与音效即会响起。

## 🕹️ 操作

| 操作 | 方式 |
|---|---|
| 查看 / 选中栖息地 | 点击地图上的栖息地 |
| 喂食 / 治疗 / 升级 | 右侧面板按钮 |
| 建造 | 底部工具栏选择工具 → 地图点击放置 |
| 开园 / 提前结业 | 顶部按钮 |
| 游戏速度 | 顶部 1x / 2x / 4x |
| 存档 | 每天日终自动保存，标题页「继续」读取 |

## 🗂️ 技术实现

- 纯原生 JavaScript + Canvas，**单文件自包含**（约 110KB），零依赖、零外部资源。
- 像素美术全部代码绘制（16×16 精灵两倍放大），含逐帧动画（动物 5 种状态、游客行走 / 排队 / 使用设施 / 心情、水体闪烁、云朵移动等）。
- Web Audio API 程序化合成全部 BGM 与音效。
- BFS 寻路驱动游客流动；拥挤检测（同格 ≥3 人）→ 道路变红 + 减速 + 满意度下降。
- localStorage 存档（`pzm_save_v1`）。
